# PortSys — دليل التشغيل السريع

هذه الحزمة تحتوي على مجلد `app` المطوّر لمشروع التخرج المبني على CodeIgniter 4. المشروع مستقل تمامًا عن SENA EXPRESS.

## أهم ما في هذه النسخة

- تبديل ثابت وواضح بين العربية والإنجليزية في الواجهة العامة، تسجيل الدخول، ولوحة التحكم.
- حفظ اللغة المختارة أثناء التنقل وبعد تسجيل الخروج، مع منع خلط صفحات العربية والإنجليزية بسبب التخزين المؤقت.
- خط `Tajawal` للعربية و`Inter` للإنجليزية مع خطوط بديلة عند انقطاع الإنترنت.
- شعار PortSys موحّد داخل النظام وأيقونة حقيقية لتبويب المتصفح بدل أيقونة XAMPP.
- صفحة مواقع احترافية تتضمن خريطة وفلاتر وبيانات ثنائية اللغة.
- كتالوج مبدئي من 51 ميناءً عالميًا حقيقيًا مع الإحداثيات والمنطقة الزمنية، ويُضاف تلقائيًا بالترحيل.
- إمكانية استعادة الكتالوج من زر «استعادة المواقع العالمية» دون تكرار السجلات.
- اختيار موقع حقيقي عند إنشاء أو تعديل ميناء لملء الاسم والدولة والمدينة وخطوط الطول والعرض تلقائيًا.
- إدراج المواقع ضمن البحث العام في لوحة التحكم.

> إحداثيات الكتالوج نقاط خرائط تمثيلية مناسبة للنظام والعروض التجريبية، وليست بيانات ملاحة بحرية.

## المتطلبات

- PHP 8.1 أو أحدث.
- مشروع CodeIgniter 4 كامل يحتوي على `public` و`writable` و`vendor` و`spark`.
- MySQL/MariaDB أو محرك مدعوم من CodeIgniter 4.
- امتدادات PHP الأساسية، خصوصًا `intl` و`mbstring` و`json` وامتداد قاعدة البيانات.

## التثبيت

1. خذ نسخة احتياطية من مجلد `app` وقاعدة البيانات.
2. استبدل مجلد `app` الحالي بالمجلد الموجود في الحزمة.
3. اضبط `.env` وفق رابط مشروعك الحقيقي. مثال XAMPP:

```ini
CI_ENVIRONMENT = development
app.baseURL = 'http://localhost/portsys/'
app.indexPage = 'index.php'
app.appTimezone = 'Asia/Damascus'

database.default.hostname = localhost
database.default.database = portsys
database.default.username = root
database.default.password =
database.default.DBDriver = MySQLi
```

4. شغّل الترحيلات من جذر المشروع الكامل:

```bash
php spark migrate
```

هذا الأمر يضيف حقول المواقع الجديدة ويُدخل كتالوج الموانئ الحقيقي تلقائيًا، مع المحافظة على المواقع القديمة.

5. لإضافة حسابات تجريبية عند الحاجة فقط:

```bash
php spark db:seed UserSeeder
```

القيم الافتراضية:

- المدير: `admin@example.com` / `PortSys@2026`
- المستخدم: `user@example.com` / `User@2026`

يفضّل تغييرها من `.env` قبل تشغيل Seeder:

```ini
PORTSYS_ADMIN_EMAIL = 'admin@example.com'
PORTSYS_ADMIN_PASSWORD = 'ضع-كلمة-مرور-قوية'
PORTSYS_USER_EMAIL = 'user@example.com'
PORTSYS_USER_PASSWORD = 'ضع-كلمة-مرور-قوية'
```

6. تأكد من قابلية الكتابة على مجلد `writable`.
7. في الإنتاج استخدم HTTPS، واضبط `CI_ENVIRONMENT = production`، ولا تستخدم الحسابات التجريبية.

## بعد التحديث

- افتح `index.php/places` للتأكد من ظهور المواقع العالمية.
- إذا كانت قاعدة البيانات قديمة ولم تظهر البيانات، نفّذ `php spark migrate` ثم اضغط «استعادة المواقع العالمية» مرة واحدة.
- بسبب تخزين المتصفح لأيقونات التبويب، استخدم `Ctrl + F5` أو أغلق التبويب وافتحه مجددًا عند أول تشغيل.
- اختبر تبديل اللغة من الصفحة الرئيسية، صفحة الدخول، وصفحة داخل لوحة التحكم. يجب أن تبقى في الصفحة نفسها وأن يتغير اتجاه الواجهة والنصوص معًا.

## ملاحظات تقنية

- Bootstrap والصور والشعار والأيقونات الأساسية موجودة داخل `app/Resources/portsys` وتُخدَّم عبر Controller داخلي.
- Font Awesome وGoogle Fonts وLeaflet/OpenStreetMap تعتمد على اتصال خارجي، مع خطوط ورسائل بديلة عند تعذر الاتصال.
- الخريطة ليست شرطًا لإدخال الموقع؛ جميع الإحداثيات تظهر أيضًا كنص ويمكن فتحها مباشرة في OpenStreetMap.
