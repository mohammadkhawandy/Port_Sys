# PortSys V3 — سجل التغييرات

## اللغة والاتجاه

- توحيد مبدّل اللغة في جميع Layouts بدل اختلافه بين صورة ونص وأيقونة.
- إظهار رمز الكرة الأرضية مع `AR` أو `EN` وقائمة واضحة للغتين.
- إعادة بناء رابط تبديل اللغة ليحافظ على الصفحة الحالية والفلاتر بدون تكرار `index.php` أو مسار المشروع.
- معالجة الصفحة الرئيسية بشكل خاص حتى لا ينتقل المستخدم المسجل إلى لوحة التحكم عند تبديل اللغة.
- المحافظة على اللغة بعد تسجيل الخروج بدل تدمير جلسة اللغة.
- إضافة ترويسات تمنع خلط استجابات اللغتين بسبب Cache المتصفح أو Proxy.
- تدقيق تطابق 843 مفتاحًا في ملفات العربية والإنجليزية.

## الخط والهوية

- اعتماد `Tajawal` للواجهة العربية و`Inter` للواجهة الإنجليزية.
- إضافة شعار Anchor موحد للواجهة العامة، لوحة التحكم، وصفحات الدخول.
- إضافة Favicon بصيغ SVG وICO وPNG، وApple Touch Icon وWeb Manifest.
- إضافة إصدار إلى روابط الأيقونات لكسر Cache أيقونة XAMPP القديمة.
- توحيد عناوين التبويب بصيغة `PortSys | اسم الصفحة`.

## المواقع والإحداثيات

- إضافة 51 موقع ميناء عالمي حقيقي ببيانات عربية وإنجليزية.
- إضافة: رمز الموقع، رمز الدولة، الدولة، المدينة، النوع، المنطقة الزمنية، الحالة، ومصدر السجل.
- إضافة Migration يحافظ على البيانات القديمة ويكمل حقولها ثم يزرع الكتالوج تلقائيًا.
- إضافة خريطة عالمية تفاعلية وفلاتر وبحث وإحصائيات للمواقع.
- إضافة خريطة اختيار قابلة للنقر والسحب في نموذج الموقع.
- إضافة زر استعادة/تحديث الكتالوج بشكل Idempotent دون إنشاء نسخ مكررة.
- ربط إنشاء وتعديل الموانئ بكتالوج المواقع لتعبئة الإحداثيات تلقائيًا.
- إضافة المواقع إلى البحث العام في لوحة التحكم.

## تحسينات إضافية

- تحسين التوافق مع روابط XAMPP التي تستخدم `index.php`.
- تحسين المحافظة على الجلسة واللغة عند تسجيل الخروج.
- إضافة تحذير واضح بأن الإحداثيات تمثيلية للنظام وليست للملاحة.
- تحسين حالات تعذر تحميل الخرائط دون كسر الصفحة.
- إضافة Cache Headers وETag للصور والأيقونات الداخلية.
